# Awesome Claude Design

`README.md` is the upstream catalog, grouped by category. `design-md/<brand>/DESIGN.md` holds the full design-system description for each brand: tokens, typography, components, layout, motion and rationale.

## How to use

1. Pick 3–6 inspirations whose **feel** matches the product brief. Pick by aesthetic family (editorial, cinematic, playful, brutalist…), not by industry.
2. Read their DESIGN.md files in full. For each one, note what it does that is transferable: how tokens are named, the type-scale logic, how color carries meaning, the component rules, and the "why".
3. Never copy a brand's palette, logo, typefaces or signature composition. Extract the **principles** and remix them into the project's own identity.
4. Write the project's DESIGN.md in the same structure (token + rule + rationale in one place). Cite which inspiration informed each decision.
